# Byzichuang

请生成一个app名叫七彩星光自创语言，分为三类账号，普通账号：普通注册界面就可以注册，此类型账号仅答题（创语账号创的题），答对加1葛掉元，答错减0.5葛掉元（答题形似以及加几葛掉元管理员设置），创语账号：由管理员注册，（写入题目及答案，也可以删除题目），管理员账号：注册或删除所有账号，封控及冻结所有账号，可以看到所有自创语言的翻译
